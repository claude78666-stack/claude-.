# Realistic mascot prompts (for Canva, Figma or any image tool)

Paste each prompt as is. Save results as `NN-name.jpg` in the folder shown. These are concept art for joke characters. Nothing is launched and none of this is an investment.

**Style suffix (already included in every prompt below):** cinematic lighting, ultra detailed, 8k, no text, no logos.
**Tips:** 1024x1024 works. If a result looks like only one of the animals, add "all three animals clearly visible" and name the two weakest parts first. Ask for no brand names or watermarks.
